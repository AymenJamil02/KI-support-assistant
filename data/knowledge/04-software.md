# Software: Installation und Lizenz beantragen

Demo-Regel: Suche die benötigte Software im internen Softwarekatalog. Wenn sie fehlt, erstelle einen Antrag mit Produktname, Einsatzzweck, benötigter Nutzerzahl und gewünschtem Startdatum.

Eine kostenpflichtige Lizenz benötigt die Freigabe der verantwortlichen Führungskraft. Die IT prüft Sicherheit und Kompatibilität. Installiere ungeprüfte Software nicht eigenständig.
