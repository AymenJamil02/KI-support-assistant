# Kurzanleitung für Anwender

1. Lokale Demo starten und die angezeigte Browseradresse öffnen.
2. Eine konkrete IT-Frage stellen, zum Beispiel „Wie beantrage ich eine Software-Lizenz?“.
3. „Antwort finden“ auswählen.
4. Die angezeigten Originalauszüge und ihre Quellen lesen.
5. „Entwurf kopieren“ nur nach Prüfung verwenden.

## Wenn keine Antwort vorhanden ist

Der Assistent erklärt, dass keine ausreichend passende Quelle gefunden wurde. Präzisiere die Frage oder wende dich an den zuständigen Support. Eine Zurückweisung bedeutet nicht, dass es im realen Unternehmen keine Regel gibt; die Demo kennt nur zwölf fiktive Anleitungen.

## Optionaler KI-Modus

Der KI-Modus benötigt ein eingerichtetes lokales Sprachmodell. Er formuliert einen Entwurf aus abgerufenen Quellen. Prüfe jede Aussage selbst. Wenn das Modell ausfällt, werden Originalauszüge angezeigt.

## Gute Fragen

- „Wie melde ich eine Phishingmail?“
- „Was gehört in ein Supportticket?“
- „Wie ändere ich meine MFA-Methode beim Smartphonewechsel?“

Keine Passwörter, Einmalcodes oder persönlichen Daten in eine Frage eingeben. Die Demo kann keine Passwörter ändern und kein echtes Ticket abschicken.
